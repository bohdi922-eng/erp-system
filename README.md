# ERP System

**To run this app:** double-click **`setup.bat`** in this folder.

First time, it needs internet for about a minute (to download styling/fonts
so the app looks right) and to install a couple of Python packages. Every
time after that, it needs no internet at all and just starts the app.

Full technical details, manual setup steps, and what's built vs. not yet
built: see [`backend/README.md`](backend/README.md).
